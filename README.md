# 隧道点云大幅正射成图

这是一个独立软件，只完成一件事：把 LAS 或 E57 隧道点云流式展开为可供外部标注软件使用的大幅正射影像。

本软件不包含标注、复核、训练集划分或 640×640 切片，也不依赖 `1_PointCloudprocessing`、`4_TunnelDefectStudio` 或 `mask_annotator` 的代码目录。

## 启动

双击：

```text
启动大幅正射成图.bat
```

也可以在本目录运行：

```powershell
python main.py
```

首次换到其他电脑时安装依赖：

```powershell
python -m pip install -r requirements.txt
```

窗口可缩放到较小尺寸；输入、输出和参数区域可独立滚动。成图参数分为“基础与几何”和“显示与 LAS 处理”两个页签，避免低分辨率屏幕上窗口过高。

## 输入约定

- 支持在文件选择窗口中一次选择多个 LAS/E57；软件会按顺序逐个成图，某个文件失败不会阻断后续文件。
- 支持未压缩 `.las`，包括 LAS 1.0–1.4、点格式 0–10。
- 支持标准 `.e57`，可包含一个或多个 `data3D` 扫描对象。
- E57 支持笛卡尔坐标；只有球坐标时由原生读取器转换为 XYZ。
- 多个 E57 扫描对象的 `pose` 会应用到坐标后再合并。
- 强度优先读取 E57 标准 `intensity`；没有强度但具有完整 RGB 时使用 RGB 亮度。
- EasyTry 转换生成且带 `rowIndex`/`columnIndex` 的 E57 会自动进入结构化模式；普通 E57 仍使用通用读取器。
- 当前不支持 `.laz`。
- LAS 和普通 E57 的坐标必须是：X 为隧道断面横向、Y 为隧道纵向米制距离、Z 为竖向。
- 结构化 EasyTry E57 使用 `columnIndex` 作为扫描断面序号；纵向米制距离在成图时按“小车速度 ÷ 每秒圈数”重新计算，不使用转换阶段的固定断面间距。
- 结构化 EasyTry E57 如果同目录存在 `点云文件名_扫描说明.txt`，还会读取“半断面行数”和“扫描角度”。例如 FARO 单侧 150° 将按真实 300° 总扫描范围展开，不会拉伸到360°。

“通用”指 LAS/E57 文件结构和标准字段，不表示任意坐标方向或任意非隧道几何都能自动展开。

## 自动任务清单

界面的“导入 Tab 分隔任务清单”支持每行两列：

```text
E:/Data/项目名/*.e57<Tab>E:\Data\项目名\ortho_outputs
```

导入后可在勾选窗口中选择本次执行的任务，默认不全选。程序会逐行展开通配符并连续处理。
界面显示当前进度和运行日志，处理结束后直接提示失败原因。日志仅保留在当前窗口中，不读取或写入日志文件；再次载入清单时会处理本次选择的全部匹配点云。
输出盘剩余空间低于 10 GB 时安全停止，释放空间后可重新选择未完成的任务。

勾选“生成正射影像后移除输入点云文件”后，普通选择文件和导入清单两种模式均生效：仅在确认完整的正射影像已经写入磁盘后，才移除该 `.e57` / `.las` 及同目录下同名的 `_扫描说明.txt`。清理失败会明确提示，影像保留。每次运行只清理本次已确认成图成功的输入；成图失败、取消或输出不完整时保留输入。
勾选“成功后从清单移除任务”后，一个任务组内的点云在本次运行中全部成功时会从原 TXT 中移除该行。

## 成图方法

1. 第一遍分块读取点云，统计纵向范围和显示强度，并抽样拟合 XZ 参考椭圆作为几何质量诊断。结构化 EasyTry E57 的纵向位置为 `columnIndex × (小车速度 ÷ 每秒圈数)`；LAS/普通 E57 使用文件中的米制 Y。
2. 结构化 EasyTry E57 根据扫描说明中的真实角度范围建立 `rowIndex → 角度`映射，并与平滑的拟合参考断面求交，按参考断面累计弧长生成图像行。轨道、设备和遮挡边缘的深度突变不会拉伸图像；未扫描的盲区不拉伸、不插值也不输出。LAS/普通 E57 仍使用参考椭圆投影。
3. 按 Y 轴真实距离建立图像列。默认生成覆盖全部范围的单张影像；若请求分辨率导致整图超过像素上限，则自动调整到不超限的最高分辨率。
4. 第二遍分块读取，同一像素内多个点的强度取平均。
5. 默认启用受限自适应补孔：根据展开栅格 31×31 邻域的观测覆盖率估计采样间距，基础距离 7.5 mm，自适应距离上限 15 mm，封闭孔面积上限 25 像素；同时限制孔洞长宽，保留大缺口、边界缺测和盲区。仅在显示图中处理缺测像素。
6. 默认使用最多 8 个邻点的距离平方反比加权平均，至少需要 3 个有效邻点；邻点灰度范围超过 80/255 显示量程，或 LAS 邻点深度范围超过前景深度簇厚度时不填补。内部窄空列仍采用双侧线性插值，同样保护灰度和深度边界。可选择最近邻方式并关闭自适应以恢复旧版补孔行为。
7. 可仅在显示 PNG 中抑制与 3×3 邻域明显不一致的孤立单像素亮点/黑点。
8. 科学强度保留为 `float32` TIFF/NPY；显示处理不改动科学强度和观测掩膜。

结构化 E57 的角度等间隔采样在换算成参考断面弧长后，局部扫描行间距可能超过像素尺寸，正向投点会留下整行空白。显示补孔现会处理受物理距离限制的内部窄空行：仅在同一列的上下两侧都有真实观测、灰度差不超过 80/255 显示量程时做线性重采样；边界空行和宽缺口保持缺测。补孔拓扑同时识别与这些空行相连的小缺孔，仍使用真实观测计算距离、覆盖率与插值值。LAS 和普通 E57 不启用此空行处理，科学强度、真实观测掩膜和命中数均保持原样；将补孔距离设为 0 可关闭。

有辅助数据的结构化 E57 旧输出可用 `rebuild_existing_display.py` 重建，新版会从运行清单识别结构化输入并启用窄空行处理。

默认开启“缺测黑点修补”：普通成图和辅助数据重建会在常规补孔后自动识别面积不超过 25 像素、长宽不超过 9 像素、长宽比不超过 4 的小黑孔，并根据周围灰度局部修补。候选区域须接近纯黑、明显暗于周边，且位于补孔物理距离上限内；贴边区域、连续长线和大缺口不处理。有真实观测的数据始终按命中数保护，修补只改变缺测显示像素，成功位置合并到插值掩膜和覆盖率统计中。开启辅助输出时保存 `display_dark_speckle_mask.png`；每幅元数据及集中输出 manifest 记录是否启用和修补像素数。取消界面选项或将补孔距离设为 0 可关闭；重建工具支持 `--no-repair-dark-speckles` 和 `--repair-dark-speckles`。

仅有 PNG 的旧输出也可按外观推断小黑点候选后局部修补；它缺少逐像素观测状态，与使用强度/命中数数组的重建应分开标识。软件正常成图始终使用真实观测状态保护已测得的暗色像素。

LAS 开启深度显示处理时会增加一遍流式读取：先统计各像素前景深度，再聚合该深度簇。科学层仍保存所有有效输入点的平均强度；显示层单独保存并仅用于 PNG。

整个点云不会一次载入内存。大幅累积栅格使用磁盘映射文件，适合处理超大 LAS/E57。

## 输出

默认不输出辅助数据，并开启“集中存放影像”。每幅正射 PNG 与对应的清单直接保存在用户选定的输出目录：

```text
输出父目录/
  输入名_ORTHO_00001.png
  manifest_输入名_ORTHO_00001.json
  输入名_ORTHO_00002.png
  manifest_输入名_ORTHO_00002.json
```

集中模式不创建输入名、`orthophotos` 或 `auxiliary` 等中间目录。每个 `manifest_{影像名}.json` 都保留本次成图的参数和影像列表，`primary_image` 指明它对应的影像。如同名影像已存在，新结果自动增加 `_2`、`_3` 后缀，不覆盖旧文件。

开启“输出辅助数据”后，“集中存放影像”会自动关闭，每个输入文件创建独立目录：

```text
输出父目录/
  输入名_时间/
    manifest.json
    orthophotos/
      输入名_ORTHO_00001.png
    auxiliary/              辅助数据，不与正射影像混放
      ORTHO_00001/
        intensity.tif         float32 科学强度
        intensity.npy         同值磁盘映射数组
        observed_mask.png     真实有点像素为1，无点为0
        interpolated_mask.png 显示图被插值的位置为1
        coverage_preview.png  红=剩余缺测，蓝=成功补孔，黑=观测低强度，灰=其他观测
        hit_count.npy         每像素点数
        image.json            本幅图的尺寸、全局窗口和真实纵向范围
```

辅助模式中，掩膜、科学强度和每幅元数据均放在 `auxiliary/ORTHO_00001` 等对应子目录中。正射图、掩膜和科学强度数据尺寸完全一致。小孔插值只作用于正射 PNG；`intensity.tif`、`intensity.npy`、`observed_mask.png` 和 `hit_count.npy` 均保留真实观测状态。

## 参数

- **像素大小**：默认 5 mm/px。
- **小车速度**：默认 0.4 m/s；仅用于结构化 EasyTry E57。
- **扫描仪每秒圈数**：默认 100 圈/s；结构化 EasyTry E57 的断面间距由“小车速度 ÷ 每秒圈数”自动计算。
- **根据扫描说明自动设定**：默认开启。每个点云会读取同目录下的 `点云文件名_扫描说明.txt`，查找 `计算得到的每秒圈数：{浮点数}圈/秒`，四舍五入保留小数点后三位再用于该文件成图。若说明包含有效正数 `小车速度：{数值} m/s`、`内径：{数值} m`，分别覆盖该文件的小车速度和预期直径；内径有效时，该文件使用已知直径校验拟合结果。`环宽：{数值} m` 暂不参与成图，保存在辅助输出的 `manifest.json` 的 `settings.ring_width_m` 中。旧说明缺少这三个新增字段，或字段标记未读取到、为零或无效时，沿用原手工设置或点云自动估算直径。结构化 E57 还会读取 `半断面行数` 和 `扫描角度`，校验 E57 行数并使用真实总扫描范围。批次内按文件分别读取参数，界面显示首个文件的预览；切换输入或关闭自动设置会恢复原手工参数。缺少扫描说明或必需的每秒圈数字段时，该文件记录失败后继续处理其他文件。
- **输出辅助数据**：默认关闭。开启后输出科学强度、观测/插值掩膜、命中数和详细元数据。
- **集中存放影像**：默认开启；影像和其 `manifest_{影像名}.json` 直接输出至指定目录。仅在关闭“输出辅助数据”时可用。如手动关闭集中存放，会保留独立运行目录、`orthophotos` 子目录和 `manifest.json`，但不保留 `auxiliary`。
- **输出模式**：默认输出完整单图。若整图超过 8000 万像素，程序按整图超出比例自动增大像素尺寸，使完整影像在上限内保留尽可能高的分辨率。关闭此选项后恢复固定分辨率分幅。
- **每幅大图纵向长度**：仅在关闭完整单图时使用，默认 20 m。
- **直径模式**：默认根据点云断面自动拟合并计算等效直径，估算值会回填界面并写入成图 manifest。如果已知设计尺寸，可关闭自动估算并填写手工预期直径，用于严格校验拟合结果。
- **纵向 Y 起止**：留空表示全部范围。
- **显示强度上下限**：留空时使用有界抽样的 1%–99% 分位；人工填写可让多批数据保持一致灰度量程。
- **显示小孔最大插值距离**：基础距离默认 7.5 mm；设为 0 关闭全部补孔，包括自适应和内部窄空列填补。
- **自适应补孔**：默认开启。局部候选半径为 `max(基础距离/像素尺寸, 2/sqrt(局部覆盖率))`，再受物理距离上限约束。默认物理上限 15 mm、封闭孔面积上限 25 像素；孔洞长宽不超过 `2×局部半径+1` 像素。覆盖率最低按 0.05 计算，仅作为显示补孔启发式，不代表测量精度；不会自动降低用户设定的分辨率。自适应上限不能小于基础距离。
- **小孔填补方式**：默认多邻点距离加权，限制邻域灰度和 LAS 深度差异。被边缘保护拒绝的位置会从插值掩膜中移除，保留缺测。最近邻方式保留旧版算法；关闭自适应并选择最近邻可做对照。
- **覆盖率诊断**：成图 manifest 保存真实观测比例、成功补孔数量、剩余缺测比例及单点命中像素数。开启辅助输出时增加 `coverage_preview.png` 分类诊断图，用于区分缺测与真实低强度；该图不用于标注。真实低强度的判定基于显示映射前的观测值，不修改强度。
- **显示杂点处理**：默认开启；只替换孤立单像素脉冲，连续线状目标和较大目标不处理，也不修改科学数据。
- **LAS 分列**：采用最近像素中心取整，避免 0.1 mm 坐标量化误差造成重复列和整幅空列。内部窄缺测列仅在左右均有观测、插值距离符合上限时显示填补；边界和大缺口不填。
- **LAS 管线边缘处理**：默认开启前景深度簇聚合，排除绝对相对深度超过 2 m 的点，并平均最前层 30 mm 深度簇内的强度。两个阈值可在界面调整，也可关闭。仅影响显示 PNG，不修改科学强度/命中数；未恢复 LAS 中丢失的原始扫描行号，不能保证消除所有边缘锯齿。
- LAS 深度处理额外保存 `display_intensity.npy`、`display_hit_count.npy` 和 `display_support_mask.png`，便于复现显示处理；原 `intensity.npy/tif`、`hit_count.npy`、`observed_mask.png` 保留全部有效输入点的栅格观测。`image.json` 记录显示剔除点数和处理阈值。
- 开启显示杂点处理时，还会在相对深度超过 0.1 m 的前景上抑制孤立灰度脉冲：3×3 邻域完整、与中值相差至少 48 灰度、邻域没有同色支持。连续线和墙面不做此处理。`display_front_depth.npy` 保存前景深度用于重建显示。

## 验证

LAS 新增**轮廓抗锯齿强度**（0..1，默认 0.5，0 关闭）：仅在完整观测支持、前景深度跨越 30 mm、灰度对比至少 40、方向一致性至少 0.6 的边缘上，沿局部轮廓切线做 ±0.75 像素双线性采样。避免全图模糊，但不能恢复扫描姿态误差、真实缺测或较长的斜向纹路。此功能需要 LAS 深度簇聚合，仅改变 PNG，不改变科学数组、显示聚合数组和命中数。`display_antialias_mask.png` 标出发生变化的像素，`image.json` 记录强度与数量。

已有 LAS 深度显示输出也可加参数 `--antialias-strength 0.5` 重建；不指定时沿用元数据，旧输出保持关闭。

```powershell
python -m pytest -q
```

原生 E57 读取器源代码位于 `native/`，编译后的 x64 版本已经放入程序包。它使用 libE57Format，仅读取输入文件。

已有旧输出无需重跑点云，可在本目录执行：

```powershell
python tools/rebuild_existing_display.py "完整的 auxiliary/ORTHO_00001 目录"
```

工具会先保留原标注图和 `image_before_interpolation.json`，再重建标注图与 `interpolated_mask.png`。

已有辅助数据可显式启用新版补孔，无需重跑点云：

```powershell
python tools/rebuild_existing_display.py "完整的 auxiliary/ORTHO_00001 目录" --adaptive --adaptive-limit-mm 15 --maximum-hole-area-pixels 25 --interpolation-method idw
```

不指定新选项时沿用每幅 `image.json` 中的策略，旧元数据保持旧版补孔方式。重建也输出覆盖率诊断图，科学数组和观测掩膜保持不变。只有 PNG 而没有强度和命中数的旧输出无法可靠区分缺测与低强度，需要重新成图。
